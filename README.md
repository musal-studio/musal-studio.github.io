# Musal Studio 공개 웹사이트

앱 소스와 별도로 관리하는 개발자 소개·개인정보처리방침 전용 저장소입니다.

- 소개: https://musal-studio.github.io/
- DogTime 정책: https://musal-studio.github.io/dogtime/privacy/
- 언어별 링크: `#ko`, `#en`, `#ja`, `#es`
- 연락처: musalhk@gmail.com

GitHub Pages는 `main` 브랜치의 루트에서 게시합니다. 새 앱은 해당 앱의
`앱이름/privacy/index.html`을 추가하고 홈페이지의 링크를 갱신합니다.
API 키·인증서·앱 소스·개인정보가 있는 레퍼런스는 이 저장소에 추가하지 않습니다.

DogTime 정책 원본은 비공개 DogTime 저장소의 `release/privacy-site/index.html`입니다.
내용을 수정할 때 앱 내부 정책과 공개 페이지를 함께 확인합니다.
